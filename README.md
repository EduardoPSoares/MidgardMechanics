Mecânicas de sobrevivência para Paper: um núcleo (`Core`) e o módulo de culinária (`FoodDecay`).

## Destaques

- **Culinária e conservação**: comida que estraga com o tempo, nutrição, líquidos, fermentação e receitas.
- **Estruturas multibloco** para as estações de preparo.
- Hologramas, partículas, GUIs e scoreboard próprios.
- Núcleo reutilizável para registrar módulos, comandos e configuração.
- Guia de uso em [`docs/guia-fooddecay`](docs/guia-fooddecay).

## Stack

Java 21 · Maven (multi-módulo) · Paper API

## Como compilar

```bash
mvn package
```
